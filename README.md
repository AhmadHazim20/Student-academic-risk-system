# Student-academic-risk-system
AI-assisted student academic performance risk identification system

1. Case Study Description

This project investigates the use of an AI-assisted application to identify students who may be at risk of poor academic performance. The application aims to help lecturers and academic advisors prioritize students who may need further academic support.

The AI-generated risk category is intended to support human decision-making. Lecturers and academic advisors remain responsible for reviewing the available evidence and deciding on appropriate follow-up actions.

2. Repository Purpose

This repository contains the assignment artifacts, including the problem statement, stakeholder and decision map, user stories and acceptance criteria, quality attribute scenarios, system architecture, initial risk register, and traceability matrix.

It also contains tools for validating the repository artifacts and a GitHub Actions workflow for automated quality checks.

3. Repository Structure

artifacts/docs/ — problem, stakeholder, requirement, architecture and decision artifacts.

risks/ — initial risk register.

traceability/ — traceability matrix.

tools/ — environment and artifact validation scripts.

.github/workflows/ — automated quality gate.

4. Reproducible Instructions

Python 3 is required to run the local validation tools.

The commands for checking the environment and validating artifacts will be documented here after the corresponding scripts have been created and tested.

GitHub Actions will be used to run the artifact validation automatically.

5. Generative AI Use Declaration

Generative AI assistance will be declared transparently in the assignment report. The declaration will describe the prompts used, the outputs considered, and how those outputs were reviewed, adapted or tested by the student.
